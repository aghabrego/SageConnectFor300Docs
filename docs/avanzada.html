Capítulo 05 · Avanzada

Conexiones, módulos e importación S50

El último capítulo reúne las cuatro pantallas del bloque CONFIGURACIÓN. Aquí se decide qué datos viajan entre Sage 300, la base local y Sage 50.

§ 01 Sage 300

Esta pantalla define el endpoint de la API y las credenciales con las que el conector se autentica contra Sage 300.

API

  • URL base: http://localhost/Sage300WebApi/v1.0
  • Empresa: BGSDAT
  • Estructura GL: IDACC

Credenciales

  • Usuario Sage 300: ADMIN
  • Contraseña: campo oculto — usa Mostrar contraseña para verificar.

Defaults para importación S50 → S300

  • CustomerGroup (AR): SLSUSD
  • VendorGroup (AP): RPRUSD

Desde aquí también se accede a Cambiar contraseña de acceso, que modifica la contraseña del Manager (no la de Sage 300).

§ 02 Base de datos

Aquí se configura el motor donde vivirán las 76 tablas sincronizadas. Hay dos proveedores disponibles; SQL Server es el habitual.

Cadena de conexión

Server=localhost;Database=SageConnect;Trusted_Connection=True;TrustServerCertificate=True;
Autenticación. Para cuentas Windows usa Trusted_Connection=True. Para autenticación SQL, sustitúyelo por User Id=sa;Password=xxxxx;.

Acciones

  • Probar conexión — verifica la cadena sin tocar nada.
  • Inicializar esquema completo (76 tablas) — crea toda la estructura.
  • Guardar — persiste los cambios.
Cuidado. La inicialización del esquema es destructiva si las tablas ya existen con otra estructura. Haz primero una copia de seguridad.

§ 03 Sincronización

Esta pantalla define qué módulos de Sage 300 viajan a la base local. Está organizada en tres bloques.

Módulos básicos

  • Clientes (AR Customers)
  • Proveedores (AP Vendors)
  • Artículos (IC Items) — requiere licencia
  • Órdenes (OE Orders) — requiere licencia
  • Cuentas GL (GL Accounts)

AR — Documentos financieros

  • Documentos posteados, recibos posteados, pagos
  • Lotes de facturas, cobros y reembolsos

AP — Documentos financieros

  • Documentos posteados
  • Lotes de facturas y pagos

§ 04 Importación S50

La última pantalla controla el flujo Sage 50 → Sage 300. Primero se habilita el switch maestro, luego se elige la fuente y los módulos a importar.

Fuente de datos

  • Imp — staging de Sage 50 (_Imp).
  • Exp — exportación directa de Sage 50 (_Exp_S50). Es la opción por defecto.
  • ID Compañía S50: 1
  • Separador GL: -

Módulos a importar

Maestros

  • Clientes, proveedores, productos, contactos y trabajos.
  • Fases, códigos de costo y ajuste de inventario no están disponibles en Exp.

Ventas

  • Facturas y órdenes de venta.

Compras

  • Facturas de compra.

Financiero

Bloque visible al hacer scroll en la pantalla original.
