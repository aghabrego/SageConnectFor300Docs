Una guía completa para desplegar el conector de sincronización entre Sage 300 ERP y la base de datos local. Desde el asistente de instalación hasta la primera sincronización manual.

§ 01 Contenido de la guía

El proceso completo se divide en cinco capítulos. Recomendamos seguirlos en orden: cada etapa prepara el terreno para la siguiente.

  1. 01 Proceso de instalación Asistente paso a paso: carpeta de destino, licencia, accesos directos y finalización. →
  2. 02 Acceso a la aplicación Cómo abrir el Manager desde el menú Inicio y autenticarse en la pantalla de login. →
  3. 03 Configuración inicial Escritorio principal e intervalos de sincronización automática. →
  4. 04 Configuración del Web Screen Despliegue paso a paso del Web API de Sage 300 en IIS y prueba del endpoint. →
  5. 05 Carga de catálogos Plan de Cuentas GL y Account Sets AP/AR desde Sage 300. →
  6. 06 Configuración avanzada Sage 300, base de datos, módulos de sincronización e importación S50 → S300. →

§ 02 Antes de empezar

Antes de ejecutar el instalador conviene tener a mano lo siguiente:

Requisitos mínimos. Windows 10 u 11, ~390 MB libres, permisos de administrador para la instalación, y conexión a Internet estable durante el asistente para validar la licencia.

Tiempo estimado

Una instalación limpia, incluyendo la primera sincronización manual, toma entre 20 y 40 minutos dependiendo del volumen de datos a importar.

Si algo falla

Cada capítulo incluye llamadas de atención y sugerencias. Si el proceso se interrumpe, suele ser seguro reiniciarlo desde la sección correspondiente.

§ 03 Lista de verificación

Antes de dar por terminada la instalación, comprueba que cada punto quedó resuelto.

  • El instalador finalizó sin errores
  • El acceso directo al Manager aparece en el escritorio
  • El inicio de sesión se realiza con éxito
  • Los intervalos de sincronización están definidos
  • El Web Screen de Sage 300 responde en localhost
  • El Plan de Cuentas GL se importó correctamente
  • Los Conjuntos AP/AR están cargados
  • Las credenciales de Sage 300 están configuradas
  • La cadena de conexión a la BD prueba correctamente
  • Los módulos de sincronización deseados están seleccionados
  • La importación S50 está habilitada y configurada
