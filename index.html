✅ Lista de verificación post-instalación

Comprueba cada paso antes de poner en marcha el conector:

  • Instalación completada sin errores
  • Acceso directo al Manager disponible
  • Inicio de sesión exitoso
  • Configuración de proceso (intervalos y reintentos)
  • Importación del Plan de Cuentas GL
  • Importación de Conjuntos de Cuentas AP/AR
  • Configuración de Sage 300 (URL, credenciales, defaults)
  • Configuración de Base de datos (cadena y esquema inicializado)
  • Selección de módulos de sincronización
  • Configuración de Importación S50

🧭 Orden recomendado

  1. Instalación: Ejecuta el instalador y completa el asistente.
  2. Acceso: Abre el Manager e inicia sesión.
  3. Configuración inicial: Define los intervalos de sincronización automática.
  4. Catálogos: Importa el Plan de Cuentas GL y los Account Sets AP/AR.
  5. Configuración avanzada: Completa Sage 300, Base de datos, Módulos e Importación S50.
  6. ¡Listo! Ejecuta la primera sincronización manual desde el Escritorio.
